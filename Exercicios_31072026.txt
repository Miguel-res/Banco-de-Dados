Desenvolver um banco de dados para uma Clínica Veterinária, aplicando os conceitos de DDL (Data Definition Language) e DML (Data Manipulation Language).

Neste exercício, você deverá criar o banco de dados, definir as tabelas, inserir registros e realizar consultas utilizando os comandos estudados em aula.


1. Crie um banco de dados chamado: ClinicaVeterinaria

Em seguida, crie pelo menos 3 tabelas relacionadas.


Cliente (id_cliente, nome, telefone, cidade)
Animal (id_animal, nome, especie, raca, idade)
id_cliente (chave estrangeira)
Consulta (id_consulta, data_consulta, valor, diagnostico, id_animal (chave estrangeira))

Relacionamentos
Um cliente pode possuir vários animais.
Um animal pode possuir várias consultas.

2 - Utilizando o comando INSERT, cadastre:

5 clientes
5 animais
5 consultas

Os registros devem possuir informações diferentes e coerentes entre si.
